Gemini

Interpret Drawing

Dimension Digest aus der Zeichnung, optional mit Review-Gate im CLI oder Web.

OpenCV

Primitives + View Boxes

Linien, Kreise, Arcs, Textregionen und Front/Top/Side-Layouts als strukturierte Hinweise.

Prompt

Build Prompt

Spec, Dimensionen, primitive Hints, Feedback und Overlay des aktuellen Champions.

Gemini

Generate CadQuery

Der Agent schreibt parametrischen Code und muss das Execution-Tool erfolgreich nutzen.

OCCT

Sandbox Execution

Subprocess erzeugt STEP, STL und Kernel-Metriken: BBox, Volumen, Faces, Solids.

Render

4-View Render

Iso, Front, Top und Right View werden als messbarer visueller Kontext gerendert.

CV Check

Reproject STEP onto Drawing

HLR-Projektion gegen Zeichnungslinien: Coverage, Chamfer, Aspect, Mismatch Cluster.

Gemini

Vision Critic

Render, Drawing, Overlay, Metrics und Code führen zu Score, Issues und Suggestions.

Gate

Accept or Refine

Score ≥ Threshold akzeptiert. Sonst geht Champion-Feedback in die nächste Runde.

Output

Final Model + Report

Bestes Modell landet in `final/` mit STEP, STL, Views, Critique und `run_result.json`.

Why CV matters

Die Kritik bekommt messbare Evidenz.

Das Modell entscheidet nicht allein aus einem hübschen Render. Die Pipeline extrahiert primitive Zeichnungsgeometrie, reprojected das STEP zurück auf die Originalansichten und gibt dem Critic konkrete Stellen, an denen Linien fehlen oder zu viel Geometrie steht.

Before loop OpenCV extrahiert Line Segments, Circles, Arcs, Centerlines, Arrows und Text Regions als Prompt-Hints.
Per iteration Der generierte STEP wird in Front/Top/Side projiziert und gegen die Zeichnungsmasken geprüft.
For critic Coverage, Aspect-Fehler und Mismatch-Cluster begrenzen False Accepts bei komplexeren Modellen.
For generator Das Overlay zeigt dem nächsten Versuch, wo Features fehlen oder überstehen, ohne Maße aus Pixeln zu raten.
